# Git Cheatsheet - Comandi Base

## Verificare lo stato
- `git status`: mostra lo stato dei file modificati o nuovi

## Salvare le modifiche
- `git add .`: aggiunge tutti i file allo stage
- `git commit -m "messaggio"`: crea un salvataggio locale
- `git push`: invia i commit su GitHub

## Cronologia
- `git log --oneline`: mostra la lista dei salvataggi passati
